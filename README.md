# 🎵 Telegram Shazam Bot

A Telegram bot that identifies songs from voice messages or audio files using the **Shazam API**.

---

## 🚀 Features
- Recognizes songs from audio or voice messages.
- Returns:
  - 🎶 Song title
  - 👨‍🎤 Artist name
  - 🔗 Streaming link (Spotify / Apple Music / YouTube if available)
- Works in private chats and groups.
